# Agents (from The Agency)

95 agent personas for Claude Code, copied from [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents)
(commit 8ae6164, MIT License, see LICENSE-agency-agents).

Only the divisions relevant to this site are included: marketing, paid media, design, sales, product, testing,
plus web engineering (frontend, WordPress/WooCommerce, CMS, code review, i18n, privacy) and a few specialists
(workflow automation, pricing, business strategy, sales outreach, customer service).
Claude Code loads every agent's description at the start of a session, so the full roster of 330 stays out of this repo.

Not served by the website: /.claude is blocked in .htaccess.
